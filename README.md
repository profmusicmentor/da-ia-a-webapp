# Da IA a Web App in Classe: Guida Pratica per Docenti

Una guida interattiva e pratica per insegnanti per trasformare prompt ed elaborati di ChatGPT, Gemini o Claude in siti web e applicazioni didattiche da condividere su Classroom o proiettare sulla LIM tramite GitHub Pages.

🔗 **Sito web online**: [https://profmusicmentor.github.io/da-ia-a-webapp/](https://profmusicmentor.github.io/da-ia-a-webapp/)

---

### Funzionalità incluse nella guida:
- **Il "Trucco d'Oro" per il Prompt**: come richiedere all'IA il file unico HTML/CSS/JS pronto all'uso.
- **I 4 Passi Guidati**: checklist interattiva con memoria di completamento (LocalStorage).
- **Calcolatore Link & QR Code LIM**: strumento per digitare username e nome repo e visualizzare subito link e QR code ingrandibile a pieno schermo per gli studenti.
- **Risoluzione Errori Comuni**: guida rapida agli errori tipici (404, file .txt, codice troncato, cache).
