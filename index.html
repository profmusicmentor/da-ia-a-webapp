Il "Trucco d'Oro" prima di iniziare

Evita il 90% degli errori

I server web solitamente collegano file separati per testi, grafica e logica. Per rendere tutto semplicissimo e incollare un blocco unico, aggiungi sempre questa formula magica in fondo alla tua richiesta all'IA:

«Forniscimi tutto in un UNICO file HTML completo, che contenga al suo interno anche il codice CSS (stile) e JavaScript (funzioni). Non dividere il lavoro in più file separati.»

La procedura in 4 fasi

Puoi spuntare ogni fase completata per non perdere il filo.

1

Crea lo spazio di lavoro (Repository)

Questa operazione si compie una sola volta per ogni app:

  1. • Accedi su github.com (la registrazione è gratuita).
  2. • Clicca sul tasto verde New per creare un nuovo contenitore (repository).
  3. •
    Repository name: assegna un nome breve senza spazi né accenti (es. quiz-romani o frazioni-3b).
  4. • Verifica che sia spuntato Public (necessario per visualizzarlo gratis con gli studenti).
  5. • Spunta la casellina Add a README file e clicca sul pulsante verde Create repository.
2

Incolla il codice generato dall'IA

Non devi scaricare file sul computer; puoi incollare il testo direttamente sul sito di GitHub:

  1. • In alto a destra nel repository, clicca su Add file → Create new file.
  2. •
    Nel campo Name your file... scrivi tassativamente:
    index.html

    Attenzione: tutto in minuscolo. È il nome convenzionale riconosciuto da ogni server web.

  3. • Copia il codice completo generato dalla tua IA (Ctrl + C).
  4. • Clicca nell'area bianca sottostante su GitHub e incolla (Ctrl + V).
  5. • Scorri in fondo alla pagina, premi il tasto verde Commit changes... e conferma.
3

Accendi il sito (GitHub Pages)

Diciamo a GitHub di convertire la pagina in un sito web navigabile da tutti:

  1. • Clicca sulla scheda in alto con la rotellina degli ingranaggi: Settings.
  2. • Nella colonna sinistra, clicca sulla voce Pages (icona del foglietto).
  3. •
    Sotto la voce Branch, clicca sul menu a tendina che segna None e seleziona main (o master). Lascia la cartella affiancata impostata su /(root).
  4. • Clicca su Save.
4

Prendi il link e provalo

  1. • Attendi circa 60-90 secondi e ricarica la pagina delle impostazioni (F5).
  2. •
    In cima comparirà un riquadro con il tuo link:
    Your site is live at: https://tuo-username.github.io/nome-app/
  3. • Clicca su Visit site: l'app si aprirà nel browser, pronta per essere condivisa!

Risoluzione rapida dei problemi

Errore 404 (File not found)

Verifica che il file si chiami esattamente index.html (tutto minuscolo). Se si chiama Index.html o app.html, rinominalo premendo sulla matita nell'editor di GitHub.

Sullo schermo compare solo testo/codice

Il file è stato inavvertitamente salvato con estensione .txt anziché .html. Modifica il nome del file eliminando .txt.

La pagina web rimane completamente bianca

L'IA ha interrotto la scrittura del codice prima della fine. Torna sulla chat e digita: «Riscrivi il codice per intero verificando che non sia troncato e senza tag interrotti».

Ho fatto una correzione ma vedo la vecchia versione

È solo la memoria cache del tuo browser. Premi Ctrl + F5 su Windows o Cmd + Shift + R su Mac per ricaricare la pagina forzatamente.
